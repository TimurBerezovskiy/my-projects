### 📐 Завдання №6

## 2. Код програми (`Main.java`)

```java
public class Main {
    public static void main(String[] args) {

        // ===================================================
        // ЗАВДАННЯ №4
        // ===================================================
        double a4 = 3.56;
        double b4 = 1.02;
        double c4 = 3.0;
        double d4 = 2.43;

        // Чисельник: корінь степеня c з tg(a)
        double num4 = Math.pow(Math.tan(a4), 1.0 / c4);

        // Знаменник: 1 + sh(b) / ln|d + c|
        double den4 = 1 + Math.sinh(b4) / Math.log(Math.abs(d4 + c4));

        // Підсумковий результат для завдання 4
        double y4 = num4 / den4;

        System.out.println("Результат завдання 4: y = " + y4);
        System.out.println("--------------------------------------------------");


        // ===================================================
        // ЗАВДАННЯ №5
        // ===================================================
        double a5 = 2.54;
        double b5 = 1.23;
        double c5 = -2.14;
        double d5 = -0.23;

        // Перша частина: 2 * cos(a^b)
        double part1_5 = 2 * Math.cos(Math.pow(a5, b5));

        // Друга частина: | arccos( - sqrt(c / d) ) |
        double part2_5 = Math.abs(Math.acos(-Math.sqrt(c5 / d5)));

        // Підсумковий результат для завдання 5
        double y5 = part1_5 + part2_5;

        System.out.println("Результат завдання 5: y = " + y5);
        System.out.println("--------------------------------------------------");


        // ===================================================
        // ЗАВДАННЯ №6
        // ===================================================
        double a6 = -1.23;
        double b6 = -0.34;
        double c6 = 0.707;
        double d6 = 2.312;

        // Перший доданок у дужках: lg|b / a|
        double term1_6 = Math.log10(Math.abs(b6 / a6));

        // Другий доданок у дужках: sqrt(sin(c) + e^d)
        double term2_6 = Math.sqrt(Math.sin(c6) + Math.exp(d6));

        // Підсумковий результат для завдання 6: 3 * (перший + другий)
        double y6 = 3 * (term1_6 + term2_6);

        System.out.println("Результат завдання 6: y = " + y6);
    }
}
```

## ❓ 4. Відповіді на контрольні питання

### 1. В чому полягає різниця між ключовими та зарезервованими словами?
* **Ключові слова (Keywords):** Це зарезервовані ідентифікатори, які компілятор мови Java використовує для визначення її синтаксису, структур управління та типів даних (наприклад: `class`, `public`, `static`, `void`, `if`, `else`, `for`, `while`, `return`, `try`, `catch`, `double`, `int`). Їхнє значення є нативно вшитим у специфікацію мови.
* **Зарезервовані слова (Reserved Words):** Це більш широка категорія. Вона включає ключові слова, а також слова, які зарезервовані розробниками Java "на майбутнє", але наразі не несуть синтаксичного навантаження (наприклад `const` та `goto`), або є спеціальними літералами мови (`true`, `false`, `null`).
* **Ключова відмінність:** Жодне зарезервоване чи ключове слово не можна використовувати у якості назв змінних, методів, класів чи пакетів (ідентифікаторів).

### 2. Які примітивні типи даних Ви знаєте? Для кожного з них наведіть приклади, коли найбільш ефективно використовувати саме цей тип.
У Java існує **8 примітивних типів даних**, які діляться на цілочисельні, з рухомою комою, символьні та логічні:

1. **`byte`** (8 біт, діапазон $-128 \dots 127$):
   * *Приклад:* Обробка бінарних даних (читання зображення/аудіофайлу через потік `InputStream`), збереження відтінків RGB (0..255 при беззнаковій обробці), рахунок у спортивній грі.
2. **`short`** (16 біт, діапазон $-32\,768 \dots 32\,767$):
   * *Приклад:* Збереження 16-бітних аудіо-семплів, рік випуску автомобіля, кількість днів у році (365).
3. **`int`** (32 біти, діапазон $-2^{31} \dots 2^{31}-1$):
   * *Приклад:* Стандартний цілочисельний тип за замовчуванням. Використовується для лічильників циклів `for`, індексів масивів, заробітної плати у гривнях, кількості товарів на складі.
4. **`long`** (64 біти, діапазон $-2^{63} \dots 2^{63}-1$):
   * *Приклад:* Точний час від 1 січня 1970 року у мілісекундах (`System.currentTimeMillis()`), розміри великих баз даних чи файлів у байтах, астрономічні відстані та маса планет.
5. **`float`** (32 біти, точності ~6-7 знаків):
   * *Приклад:* Графічні двигуни та 3D-ігри (OpenGL/Vulkan), де важлива швидкість обчислень та економія пам'яті GPU, а надвисока точність не потрібна (наприклад, координати текстур, позиція спавну ворога).
6. **`double`** (64 біти, точності ~15-17 знаків):
   * *Приклад:* Фінансові та математичні розрахунки, обчислення тригонометричних виразів, фізичні симуляції (обчислення орбіт супутників, траєкторії польоту).
7. **`char`** (16 біт, беззнаковий, Unicode від $0$ до $65\,535$):
   * *Приклад:* Збереження окремого символу тексту (наприклад `'A'`, `'₴'`, `'\n'`), код у таблиці Unicode.
8. **`boolean`** (1 біт логічного значення):
   * *Приклад:* Збереження логічного стану прапорця: `isUserActive`, `hasPermission`, `isGameOver`.

### 3. Що таке знакові та беззнакові типи? До якої групи відноситься кожен з примітивних типів даних?
* **Знакові типи (Signed):** Використовують один біт (найстарший, значний) для зберігання інформації про знак числа (`0` вказує на додатне число або нуль, `1` — на від’ємне). Половина діапазону відведена під від'ємні значення.
* **Беззнакові типи (Unsigned):** Усі біти пам'яті використовуються виключно для збереження величини числа. Значення не можуть бути від'ємними (діапазон від $0$ до $2^N - 1$).

**Розподіл типів даних у Java:**
* **Цілочисельні знакові:** `byte`, `short`, `int`, `long`.
* **Єдиний беззнаковий примітив:** **`char`** (приймає значення від $0$ до $65\,535$, оскільки коди символів Unicode не бувають від'ємними).
* **Типи з рухомою комою (`float`, `double`):** Зберігають знак за специфікацією стандарту IEEE 754 (мають окремий біт знаку).
* **Логічний тип `boolean`:** Не є числовим типом, тому поняття знаку до нього не застосовується.

### 4. Яке максимальне число можна записати у змінну типу short, char, int, long?
* **`short`** (16 біт, знаковий): $2^{15} - 1 = \mathbf{32\,767}$
* **`char`** (16 біт, беззнаковий): $2^{16} - 1 = \mathbf{65\,535}$
* **`int`** (32 біти, знаковий): $2^{31} - 1 = \mathbf{2\,147\,483\,647}$
* **`long`** (64 біти, знаковий): $2^{63} - 1 = \mathbf{9\,223\,372\,036\,854\,775\,807}$

### 5. Чому змінна типу byte може приймати значення у діапазоні -128..127? Чому від’ємних значень більше ніж додатних?
Тип `byte` складається з **8 біт** (1 байт). Кількість унікальних комбінацій становить $2^8 = 256$.

У Java представлення від'ємних чисел базується на **доповняльному коді (Two's complement)**:
1. За знак відповідає найстарший біт (8-й біт):
   * Якщо 8-й біт дорівнює `0` — число додатне або нуль.
   * Якщо 8-й біт дорівнює `1` — число від'ємне.
2. Число **0** записується як `00000000` (має знаковий біт `0`), тому воно належить до діапазону додатних комбінацій.
3. Додатний діапазон: від `00000001` (1) до `01111111` (127) — разом із нулем це **128 комбінацій** ($0 \dots 127$).
4. Від'ємний діапазон: від `11111111` (-1) до `10000000` (-128) — це ще **128 комбінацій** ($-128 \dots -1$).

*Висновок:* Оскільки нуль зайняв один із кодових комбінацій із додатним знаком, для строго додатних чисел залишилося 127 значень, тоді як для від'ємних — 128.

### 6. Що таке система числення? Як переводити значення з однієї системи числення у іншу?
**Система числення** — це сукупність синтаксичних правил та символів для позначення та обчислення кількісних величин. Системи бувають:
* **Позиційні:** Значення цифри залежить від її позиції (розряду) у числі (наприклад: двійкова (2), вісімкова (8), десяткова (10), шістнадцяткова (16)).
* **Непозиційні:** Значення символу стабільне і не залежить від позиції (наприклад: римські цифри XIV).

**Алгоритми переводу:**
1. **З 10-ткової у будь-яку іншу систему (наприклад, двійкову):**
   * Послідовно ділимо десяткове число на основу нової системи (на 2).
   * Записуємо остачі від ділення (0 або 1).
   * Процес продовжується, поки частка не стане рівною 0.
   * Результат зчитується шляхом виписування остач **у зворотному порядку** (від останньої до першої).
2. **З будь-якої позиційної системи у 10-ткову:**
   * Множимо значення кожної цифри на основу системи, піднесену до степеня її позиційного індексу (нумерується зправа наліво від 0):
     $$1101_2 = 1 \cdot 2^3 + 1 \cdot 2^2 + 0 \cdot 2^1 + 1 \cdot 2^0 = 8 + 4 + 0 + 1 = 13_{10}$$

### 7. Що таке «Доповняльний код»?
**Доповняльний код (Two's complement)** — це стандартний математичний спосіб подання від'ємних цілих чисел у комп'ютерній техніці.

**Перевага:** Він дає змогу замінити операцію віднімання ($A - B$) операцією додавання ($A + (-B)$), усуваючи необхідність створення окремого апаратного віднімача у процесорі.

**Алгоритм отримання доповняльного коду для від'ємного числа (на прикладі -5 для 8-бітного `byte`):**
1. Записуємо модуль числа +5 у двійковому вигляді: `00000101`.
2. Виконуємо інверсію всіх бітів (отримуємо зворотний код / інверсію): `11111010`.
3. Додаємо `1` до молодшого біта:
   $$\begin{array}{r@{\quad}l} 11111010 \\ + \phantom{1111100} 1 \\ \hline 11111011 \end{array}$$
Отже, число `-5` у пам'яті зберігається як `11111011`.

### 8. Пояснити результат роботи такого фрагмента коду:
```java
int a = 2_000_000_000;
int b = 2_000_000_000;
int c = a + b;
System.out.println(c);
```
**Результат у консолі:** `-294967296`

**Детальний розбір причини:**
1. Фактична математична сума: $2\,000\,000\,000 + 2\,000\,000\,000 = 4\,000\,000\,000$.
2. Максимальна межа типу `int` становить $2\,147\,483\,647$ (`Integer.MAX_VALUE`).
3. Оскільки $4\,000\,000\,000 > 2\,147\,483\,647$, виникає **цілочисельне переповнення (Integer Overflow)**.
4. У двійковому представленні $4\,000\,000\,000$ потребує 33 біти (`11110100001001000000000000000000`), але `int` зберігає лише молодші 32 біти: `11101000010010000000000000000000`.
5. Оскільки найстарший біт отриманого 32-бітного числа дорівнює `1`, процесор трактує його за правилами доповняльного коду як від'ємне число, яке дорівнює `-294967296`.

### 9. Чим тип float відрізняється від double?
| Критерій | `float` | `double` |
| :--- | :--- | :--- |
| **Обсяг пам'яті** | 4 байти (32 біти) | 8 байт (64 біти) |
| **Точність (мантиса)** | 23 біти (~6–7 десяткових цифр) | 52 біти (~15–17 десяткових цифр) |
| **Діапазон експоненти** | $1.4 \cdot 10^{-45} \dots 3.4 \cdot 10^{38}$ | $4.9 \cdot 10^{-324} \dots 1.8 \cdot 10^{308}$ |
| **За замовчуванням у Java** | Потребує суфікс `f` / `F` (`3.14f`) | Тип за замовчуванням для всіх літералів із комою (`3.14`) |
| **Сфера використання** | 3D-графіка, ігрові двигуни, мобільні додатки | Наукові, інженерні та фінансові розрахунки |

### 10. Що таке число з рухомою комою? Що таке мантиса та степінь?
**Число з рухомою комою (Floating-point representation)** — це стандарт представлення дійсних чисел у пам'яті ЕОМ згідно зі специфікацією IEEE 754 у формі:
$$\pm M \cdot B^E$$

Де:
* **Мантиса ($M$, Significand / Mantissa):** Дробова частина нормалізованого числа ($1.0 \le M < 2.0$ у двійковій системі). Вона визначає **точність** (кількість значущих цифр числа).
* **Основа ($B$):** Основа системи числення (у комп'ютерах завжди $B = 2$).
* **Степінь / Порядок ($E$, Exponent):** Ціле число, яке визначає масштаб (положення коми) та вказує на скільки розрядів зміщується мантиса. Порядок визначає **діапазон** (від найменшого до найбільшого можливого числа).

---

### 11. Що таке Double.NaN?
`Double.NaN` (*Not a Number* — не число) — це спеціальне константне значення типу `double`, визначене стандартом IEEE 754, яке сигналізує про те, що результат математичної операції є математично неокресленим або невизначеним у дійсному полі чисел.

**Приклади операцій, що дають `Double.NaN`:**
* Ділення нуля на нуль: `0.0 / 0.0`
* Нескінченність мінус нескінченність: `Double.POSITIVE_INFINITY - Double.POSITIVE_INFINITY`
* Квадратний корінь з від'ємного числа: `Math.sqrt(-4.0)`
* Обчислення тригонометричних методів поза областю визначення: `Math.acos(2.5)` або `Math.asin(-1.5)`.

### 12. Пояснити результат роботи такого фрагменту коду:
```java
System.out.println(Double.NaN == Double.NaN);
```
**Результат у консолі:** `false`

**Глибоке пояснення:**
Згідно зі специфікацією стандарту IEEE 754 та мови Java, константа `NaN` має унікальну властивість: **вона не дорівнює жодному значенню, включаючи саму себе**.
Тобто `Double.NaN == Double.NaN` завжди обчислюється як `false`.

**Як правильно перевіряти число на `NaN`:**
Використовувати статичний метод `Double.isNaN(value)` або порівняння `value != value` (яке поверне `true` тільки тоді, коли `value` є `NaN`).

### 13. Преінкремент та постінкремент: різниця та приклади
* **Преінкремент (`++i`):** Спочатку виконується збільшення значення змінної `i` на 1, і лише після цього нове значення повертається для використання у виразі.
* **Постінкремент (`i++`):** Спочатку повертається поточне (старе) значення змінної `i` для обчислення виразу, і тільки після цього змінна збільшується на 1.

**Приклад коду, де результати відрізняються:**
```java
int a = 10;
int b = 10;

int res1 = ++a * 2; // a стане 11, res1 = 11 * 2 = 22
int res2 = b++ * 2; // res2 = 10 * 2 = 20, після чого b стане 11

System.out.println("res1 = " + res1 + ", res2 = " + res2); 
// Виведе: res1 = 22, res2 = 20
```

### 14. В чому різниця між логічною та побітовою операцією AND? Чому `&` є в обох варіантах, а `&&` лише тільки логічна?
* **Побітове AND (`&`):**
  1. Для цілочисельних типів виконує побітове множення кожного біта двох чисел (`1 & 1 = 1`, решта `0`).
  2. Для типів `boolean` виконує логічне AND, але **без короткого замикання (non-short-circuit)**: компілятор завжди обчислює і лівий, і правий операнди, навіть якщо лівий виявився `false`.
* **Логічне короткозамкнуте AND (`&&`):**
  Працює **виключно** з типом `boolean`. Має властивість **короткого замикання (short-circuit)**: якщо лівий операнд дорівнює `false`, правий операнд **узагалі не обчислюється**, оскільки підсумковий результат виразу в будь-якому випадку буде `false`.

**Чому `&&` є тільки логічною:**
Для цілих чисел операція `&&` не має фізичного сенсу, оскільки для формування побітового результату компілятор зобов'язаний повністю прочитати та обробити обидва бінарні числа.

### 15. В чому різниця між OR та XOR?
* **OR (Логічне або побітове АБО — `|` / `||`):**
  Повертає `true` (або біт 1), якщо **хоча б один** з операндів дорівнює `true` (або 1). Якщо обидва операнди `true`, результат залишається `true`.
* **XOR (Виключне АБО / Exclusive OR — `^`):**
  Повертає `true` (або біт 1) **тільки тоді, коли операнди є різними** (один `true`, один `false`). Якщо обидва операнди однакові (обидва `true` або обидва `false`), повертається `false`.

**Таблиця істинності:**
| Операнд A | Операнд B | A OR B (`|`) | A XOR B (`^`) |
| :---: | :---: | :---: | :---: |
| `false` | `false` | `false` | `false` |
| `true` | `false` | `true` | **`true`** |
| `false` | `true` | `true` | **`true`** |
| `true` | `true` | `true` | **`false`** |

### 16. Проаналізувати наступний фрагмент програми. Передбачити його результат. Запустити. Пояснити.
```java
boolean a = true && false | false;
System.out.println(a = false);

boolean b = true && false || false;
System.out.println(b = true);
```

**Очікуване консольне виведення:**
```text
false
true
```

**Аналітичне пояснення:**
1. **Перша частина:**
   * Створення змінної: `boolean a = true && false | false;`. Операція `false | false` дає `false`, потім `true && false` дає `false`. Змінній `a` присвоюється `false`.
   * Друк у консоль: `System.out.println(a = false);`. Усередині дужок використано одиночний оператор **присвоєння (`=`)**, а не порівняння (`==`). Оператор присвоєння повертає значення, яке було присвоєне змінній (`false`). Отже, виводиться **`false`**.
2. **Друга частина:**
   * Створення змінної: `boolean b = true && false || false;` (значення `b` стає `false`).
   * Друк у консоль: `System.out.println(b = true);`. ТУТ ТАКОЖ використовується оператор **присвоєння (`=`)**. Змінній `b` присвоюється значення `true`, і вираз повертає `true`. Отже, виводиться **`true`**.
