## Завдання 2

### Умова
Обчислити суму ряду:

$$
\sum_{i=1}^{k} \ln(-t \cdot i) \cdot \cos\left(\sqrt{s \cdot \frac{1}{i^2}}\right), \quad 2 < k \le 25
$$


### Як я це робив
- Спочатку я розібрав обмеження на змінні (ОДЗ):
  - Значення $k$ за умовою має бути в межах від 3 до 25 включно ($2 < k \le 25$).
  - Під знаком натурального логарифма стоїть вираз $-t \cdot i$. Оскільки індекс $i$ змінюється від 1 до $k$ ($i \ge 1$), щоб аргумент логарифма був додатним, параметр $t$ обов'язково має бути від'ємним ($t < 0$).
  - Під квадратним коренем вираз $s \cdot \frac{1}{i^2}$ має бути невід'ємним, тому $s \ge 0$.
- Створив клас `Task2` та реалізував метод `calculateSum(double t, double s, int k)`.
- На початку методу через `if` перевіряю всі параметри. Якщо вони виходять за межі допустимих або передано `NaN`, викидаю стандартне виключення `IllegalArgumentException`, як вимагалося в завданні. Метод не взаємодіє з консоллю напряму.
- Для обчислення суми використав цикл `for` від 1 до $k$, де на кожному кроці рахую доданок і додаю його до суми `sum`. Щоб ділення було дійсним, привів типи через `(double) i`.
- У методі `main` викликаю допоміжний метод `printResults` з різними параметрами (як правильними, так і помилковими), щоб перевірити обробку виключень через `try-catch`.

### Програма:
```java
package lab03;

public class Task2 {

    public static void main(String[] args) {
        // Дозволені комбінації аргументів
        printResults(-1.0, 4.0, 3);
        printResults(-2.0, 0.0, 5);
        printResults(-0.5, 9.0, 10);
        printResults(-1.0, 1.0, 25);

        // Заборонені комбінації: порушення умов для k (потрібно 2 < k <= 25)
        printResults(-1.0, 4.0, 2);
        printResults(-1.0, 4.0, 1);
        printResults(-1.0, 4.0, 0);
        printResults(-1.0, 4.0, 26);

        // Заборонені комбінації: порушення для t (потрібно t < 0) та s (потрібно s >= 0)
        printResults(0.0, 4.0, 5);
        printResults(1.0, 4.0, 5);
        printResults(-1.0, -4.0, 5);
        printResults(Double.NaN, 4.0, 5);
    }

    /**
     * Обчислює суму ряду: \sum_{i=1}^{k} ln(-t * i) * cos(sqrt(s * (1 / i^2))).
     */
    public static double calculateSum(double t, double s, int k) {
        if (k <= 2 || k > 25) {
            throw new IllegalArgumentException("param k = " + k);
        }
        if (t >= 0 || Double.isNaN(t)) {
            throw new IllegalArgumentException("param t = " + t);
        }
        if (s < 0 || Double.isNaN(s)) {
            throw new IllegalArgumentException("param s = " + s);
        }

        double sum = 0;
        for (int i = 1; i <= k; i++) {
            sum += Math.log(-t * i) * Math.cos(Math.sqrt(s / ((double) i * i)));
        }
        return sum;
    }

    static void printResults(double t, double s, int k) {
        System.out.print("t:" + t + " s:" + s + " k:" + k + " result:");
        try {
            System.out.println(calculateSum(t, s, k));
        } catch (IllegalArgumentException e) {
            System.out.println("EXCEPTION! " + e.getMessage());
        }
    }
}
```

## Завдання 7

### Умова
Обчислити значення функції:

$$
x(t, i) = \begin{cases}
\ln(t), & i = 1, 2 \\
\sum_{k=1}^{i} \frac{\sin(t)}{k}, & i > 2
\end{cases}
$$


### Як я це робив
- Тут задана кускова функція, яка має дві гілки залежно від значення параметра $i$.
- Обмеження: параметр $i$ повинен бути не менше 1 ($i \ge 1$). Для першої гілки ($i = 1$ або $i = 2$) аргумент $t$ має бути строго більшим за нуль ($t > 0$), бо не можна брати логарифм від нуля чи від'ємного числа.
- Створив клас `Task7` і метод `calculateX(double t, int i)`.
- Спочатку перевірив параметри: якщо $i < 1$ або $t$ є `NaN` — викидаю `IllegalArgumentException`.
- За допомогою умовного оператора `if-else` зробив розгалуження:
  - якщо $i == 1$ або $i == 2$, перевіряю умову $t > 0$ і повертаю `Math.log(t)`;
  - якщо $i > 2$, запускаю цикл `for` від $k = 1$ до $i$, де накопичую суму часток `Math.sin(t) / k`.
- У `main` протестував обидві гілки функції та некоректні дані ($i \le 0$ та $t \le 0$).

### Програма:
```java
package lab03;

public class Task7 {

    public static void main(String[] args) {
        // Дозволені значення для першої гілки (i = 1, 2)
        printResults(1.0, 1);
        printResults(Math.E, 1);
        printResults(10.0, 2);

        // Дозволені значення для другої гілки (i > 2)
        printResults(Math.PI / 2, 3);
        printResults(0.0, 4);
        printResults(1.5, 5);

        // Заборонені значення: некоректне i
        printResults(2.0, 0);
        printResults(2.0, -1);

        // Заборонені значення: t <= 0 для першої гілки
        printResults(0.0, 1);
        printResults(-2.0, 2);

        // Спеціальні некоректні значення
        printResults(Double.NaN, 3);
    }

    /**
     * Обчислює значення функції x(t, i).
     */
    public static double calculateX(double t, int i) {
        if (i < 1) {
            throw new IllegalArgumentException("param i = " + i);
        }
        if (Double.isNaN(t)) {
            throw new IllegalArgumentException("param t = " + t);
        }

        if (i == 1 || i == 2) {
            if (t <= 0) {
                throw new IllegalArgumentException("param t = " + t);
            }
            return Math.log(t);
        } else {
            double sum = 0;
            for (int k = 1; k <= i; k++) {
                sum += Math.sin(t) / k;
            }
            return sum;
        }
    }

    static void printResults(double t, int i) {
        System.out.print("t:" + t + " i:" + i + " result:");
        try {
            System.out.println(calculateX(t, i));
        } catch (IllegalArgumentException e) {
            System.out.println("EXCEPTION! " + e.getMessage());
        }
    }
}
```

## Завдання 12

### Умова
Обчислити нескінченну суму із заданою точністю $\varepsilon$ ($\varepsilon > 0$):

$$
\sum_{i=1}^{\infty} \frac{1}{i(i + 1)}
$$

Вважати, що необхідна точність досягнута, якщо черговий доданок виявився за модулем меншим, ніж $\varepsilon$. Цей і всі наступні доданки можна не враховувати.

### Як я це робив
- За умовою потрібно рахувати суму нескінченного ряду, поки черговий доданок за модулем не стане меншим за задану точність $\varepsilon$. Як тільки доданок менший за $\varepsilon$, цикл переривається і цей доданок до суми вже не додається.
- Точність $\varepsilon$ повинна бути строго додатною ($\varepsilon > 0$).
- Створив клас `Task12` та метод `calculateInfiniteSum(double eps)`.
- На початку перевіряю: якщо `eps <= 0` або `Double.isNaN(eps)` — викидаю `IllegalArgumentException`.
- Для підсумовування використав цикл `while (true)`. На кожному кроці обчислюю черговий доданок `term = 1.0 / ((double) i * (i + 1))`. Якщо `Math.abs(term) < eps`, роблю `break` і виходжу з циклу. Інакше — додаю `term` до суми та збільшую $i$ на 1.
- Оскільки це телескопічний ряд і його точна сума дорівнює 1, то зі зменшенням $\varepsilon$ результат дійсно наближається до 1.0.

### Програма:
```java
package lab03;

public class Task12 {

    public static void main(String[] args) {
        // Дозволені значення точності
        printResults(0.1);
        printResults(0.01);
        printResults(0.001);
        printResults(1e-5);

        // Заборонені значення (eps <= 0 або NaN)
        printResults(0.0);
        printResults(-0.01);
        printResults(Double.NaN);
    }

    /**
     * Обчислює нескінченну суму ряду 1 / (i * (i + 1)) із точністю eps.
     */
    public static double calculateInfiniteSum(double eps) {
        if (eps <= 0 || Double.isNaN(eps)) {
            throw new IllegalArgumentException("param eps = " + eps);
        }

        double sum = 0;
        int i = 1;
        while (true) {
            double term = 1.0 / ((double) i * (i + 1));
            if (Math.abs(term) < eps) {
                break;
            }
            sum += term;
            i++;
        }
        return sum;
    }

    static void printResults(double eps) {
        System.out.print("eps:" + eps + " result:");
        try {
            System.out.println(calculateInfiniteSum(eps));
        } catch (IllegalArgumentException e) {
            System.out.println("EXCEPTION! " + e.getMessage());
        }
    }
}
```

## Контрольні питання

### 1. Що таке структурне програмування?
**Структурне програмування** — це методологія розробки програмного забезпечення, що базується на представленні програми у вигляді ієрархічної структури блоків (модулів/підпрограм) і використанні лише трьох базових логічних структур керування: послідовного виконання, розгалуження та повторення (циклу). Воно виключає безладні переходи між довільними ділянками коду (відмова від оператора `goto`), що робить структуру програми лінійною, передбачуваною, легкою для читання, тестування та супроводу.

### 2. Назвіть основні конструкції структурного програмування.
Згідно з теоремою Бема — Якопіні, будь-який обчислюваний алгоритм можна виразити за допомогою трьох базових керуючих конструкцій (кожна з яких має строго **один вхід і один вихід**):
1. **Послідовність (Sequence):** послідовне поетапне виконання інструкцій одна за одною.
2. **Розгалуження (Selection / Alternation):** вибір однієї з гілок виконання залежно від істинності умови (`if`, `if-else`, `switch`).
3. **Повторення / Цикл (Iteration / Repetition):** багаторазове виконання фрагмента коду, поки виконується певна умова (`while`, `do-while`, `for`).

### 3. Назвіть основні принципи структурного програмування.
1. **Принцип модульності (декомпозиції):** складна задача розбивається на простіші, логічно завершені підзадачі (методи, функції, підпрограми).
2. **Проектування "зверху-вниз" (Top-down design):** розробка починається із загальної архітектури з поступовою деталізацією компонентів.
3. **Обмеження базових конструкцій:** використання виключно трьох структур керування (послідовність, вибір, цикл).
4. **Принцип одного входу та одного виходу (Single entry, single exit):** кожен блок коду, цикл або функція повинні мати чітко одну точку входу та одну точку виходу.
5. **Відмова від неконтрольованих переходів:** уникнення оператора безумовного переходу `goto`.

### 4. Поясніть, чому в більшості мов програмування не радять використовувати оператор GOTO, а в мові Java його взагалі немає?
Оператор `goto` дозволяє здійснювати безумовний перехід до довільної мітки в коді. Це порушує локальність та ієрархічність програми:
- Програма стає заплутаною, важко простежити стан змінних та логіку виконання (виникає так званий "спагеті-код").
- Ускладнюється оптимізація коду компілятором і верифікація правильності програми.
- У мові **Java** ключове слово `goto` є зарезервованим (reserved keyword), але не використовується. Його вилучено на рівні дизайну мови, оскільки будь-яку логіку можна елегантно реалізувати за допомогою циклів, методів, обробки виключень (`try-catch-finally`) та іменованих переходів (`break` і `continue` з мітками).

### 5. Що таке спагеті-код?
**Спагеті-код (Spaghetti code)** — зневажлива назва заплутаного, погано структурованого та неорганізованого коду програми, потік виконання якого складно зрозуміти через надмірну кількість неструктурованих переходів, змішування рівнів абстракції, відсутність чіткої модульності та порушення меж блоків. Свою назву термін отримав за аналогією з тарілкою спагеті, де окремі нитки переплетені так, що неможливо знайти їхні початки й кінці.

### 6. Що таке проектування зверху-вниз? В чому його переваги?
**Проектування зверху-вниз (Top-Down Design, покрокова деталізація):**  
Підхід до розробки ПЗ, за якого спочатку визначається загальна ціль і архітектура програми на найвищому рівні абстракції, а потім вона послідовно розбивається на менші підсистеми, модулі та окремі підпрограми (методи), аж до конкретних елементарних операцій.  
**Переваги:**
- Дозволяє розробнику сконцентруватися на ключовій логіці, не відволікаючись завчасно на низькорівневі деталі реалізації.
- Сприяє логічній ізоляції модулів та спрощує командну розробку (можна паралельно реалізовувати інтерфейси та підмодулі).
- Полегшує тестування та локалізацію помилок (можна використовувати методи-заглушки / stubs).

### 7. Що таке область видимості ідентифікатора?
**Область видимості (Scope):**  
Частина тексту програми, всередині якої оголошений ідентифікатор (ім'я змінної, константи, методу, класу тощо) є дійсним, доступним і до нього можна звертатися безпосередньо за іменем. В мові Java область видимості визначається місцем його оголошення та зазвичай обмежується блоком коду `{ ... }`, у якому його оголошено.

### 8. Що таке блок? Як блоки впливають на область видимості?
**Блок (Block):**  
Послідовність з нуля або більше операторів, узята у фігурні дужки `{ ... }`.  
**Вплив на область видимості:**
- Змінна, оголошена всередині блоку, є **локальною** для цього блоку.
- Вона створюється в момент виконання оголошення і перестає існувати (виходить з області видимості) після виходу керування за межі закриваючої дужки `}`.
- Внутрішні блоки мають доступ до змінних зовнішніх блоків, але зовнішні блоки не мають доступу до змінних, оголошених усередині їхніх вкладених блоків.
- В Java заборонено "перекривати" (shadowing) локальну змінну зовнішнього блоку оголошенням змінної з тим самим іменем у вкладеному блоці того самого методу.

### 9. Наведіть приклади, у яких випадках краще використовувати наступні оператори та конструкції:
- **`if`:**  
  Коли потрібно виконати дію лише за умови істинності виразу, а у разі хибності нічого робити не треба (однобічне розгалуження).  
  *Приклад:* валідація аргументів або вихід із циклу:
  ```java
  if (k <= 2 || k > 25) {
      throw new IllegalArgumentException("Invalid k");
  }
  ```
- **`if-else`:**  
  Коли є взаємовиключні дії для істинного та хибного стану умови (двобічне розгалуження).  
  *Приклад:* вибір одного з двох варіантів:
  ```java
  if (score >= 60) {
      status = "Passed";
  } else {
      status = "Failed";
  }
  ```
- **ланцюги `if - else if - else if...`:**  
  Коли перевіряється серія різних умов або діапазонів значень, що не зводяться до константних рівностей.  
  *Приклад:* визначення оцінки за шкалою ECTS:
  ```java
  if (points >= 90) grade = 'A';
  else if (points >= 82) grade = 'B';
  else if (points >= 75) grade = 'C';
  else grade = 'F';
  ```
- **`switch`:**  
  Коли перевіряється одна дискретна змінна на рівність одній із багатьох фіксованих констант (цілих чисел, символів, рядків `String` або констант переліків `enum`).  
  *Приклад:* меню команд або вибір дії за кодом дня тижня:
  ```java
  switch (dayOfWeek) {
      case 1 -> "Monday";
      case 2 -> "Tuesday";
      default -> "Other day";
  }
  ```
- **тернарна умовна операція `?:`:**  
  Коли потрібно компактно вибрати одне з двох **значень** (для присвоєння змінній або передачі в аргумент методу), а не виконати блок операторів.  
  *Приклад:*
  ```java
  double max = (a > b) ? a : b;
  ```

### 10. Наведіть приклади, у яких випадках краще використовувати наступні оператори та конструкції:
- **`while`:**  
  Цикл з передумовою. Використовується тоді, коли кількість повторень заздалегідь невідома, умова перевіряється до початку ітерації, і тіло циклу може не виконатися жодного разу.  
  *Приклад:* зчитування з потоку або обчислення нескінченного ряду до досягнення точності:
  ```java
  while (Math.abs(term) >= eps) {
      sum += term;
      term = calculateNextTerm();
  }
  ```
- **`do-while`:**  
  Цикл з післяумовою. Гарантує виконання тіла циклу **щонайменше один раз**, оскільки умова перевіряється наприкінці ітерації.  
  *Приклад:* введення даних користувача з консолі з повторним запитом у разі помилки:
  ```java
  do {
      System.out.print("Введіть число > 0: ");
      val = scanner.nextInt();
  } while (val <= 0);
  ```
- **`for`:**  
  Цикл із параметром (лічильником). Найкраще підходить, коли кількість ітерацій або діапазон зміни індексу відомі заздалегідь.  
  *Приклад:* сумування від 1 до $k$ або ітерація по масиву:
  ```java
  for (int i = 1; i <= k; i++) {
      sum += Math.log(-t * i);
  }
  ```

### 11. Чим оператор break відрізняється від оператора continue?
- **`break`:**  
  Негайно **перериває та повністю завершує** виконання найближчого зовнішнього циклу (`for`, `while`, `do-while`) або блоку `switch`, передаючи керування на перший оператор після цього циклу/блоку.
- **`continue`:**  
  Не завершує весь цикл, а лише **достроково перериває поточну ітерацію** циклу. Керування передається на блок оновлення лічильника (у циклі `for`) або одразу на перевірку умови (у циклах `while` / `do-while`), після чого починається наступна ітерація.

### 12. Навіщо у мові Java є мітки, якщо немає goto?
У Java мітки (labels) використовуються виключно у поєднанні з операторами `break` та `continue` для управління **багаторівневими вкладеними циклами** (Labeled break/continue).  
За замовчуванням `break` чи `continue` діють лише на найглибший (внутрішній) цикл. Якщо потрібно з глибини кількох вкладених циклів достроково вийти із самого зовнішнього циклу (або перейти до його наступної ітерації), використовується оператор з міткою:
```java
outerLoop:
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        if (matrix[i][j] == target) {
            found = true;
            break outerLoop; // Вихід з обох циклів одночасно
        }
    }
}
```
Це безпечна та структурована альтернатива `goto`, яка не дозволяє переходити у довільні місця коду.

### 13. До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.
```java
boolean a = false;
boolean b = false;        
if (a=false) {
    System.out.println("a is false");
} 
if (b=true) {
    System.out.println("b is true");
}
if (a=b) {
    System.out.println("a = b");
}
```

#### Результат роботи:
```text
b is true
a = b
```

#### Пояснення:
1. В операторах `if` використано **оператор присвоєння** `=` замість оператора порівняння `==`.
2. В мові Java вираз присвоєння повертає присвоєне значення.
3. `if (a = false)`: змінній `a` присвоюється `false`. Сам вираз повертає `false`. Умова `if (false)` є хибною, тіло першого `if` не виконується (рядок `"a is false"` НЕ виводиться).
4. `if (b = true)`: змінній `b` присвоюється значення `true`. Сам вираз повертає `true`. Умова `if (true)` є істинною, тому виконується `System.out.println("b is true");`. Відтепер значення `b` дорівнює `true`.
5. `if (a = b)`: змінній `a` присвоюється поточне значення змінної `b` (тобто `true`). Вираз обчислюється як `true`. Умова виконується, і на екран виводиться `"a = b"`.

### 14. До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.
```java
int a = 1;
a++;
++a;        
switch(a) {
    case 1: System.out.println("1");
    case 2: System.out.println("2");
    case 3: System.out.println("3");
    case 4: System.out.println("4");            
}
```

#### Результат роботи:
```text
3
4
```

#### Пояснення:
1. Початково `a = 1`.
2. Після `a++` значення `a` стає 2.
3. Після `++a` значення `a` стає 3.
4. Конструкція `switch(a)` зіставляє значення `a` (3) з мітками `case`.
5. Відбувається перехід до `case 3:`, де викликається `System.out.println("3")`.
6. Оскільки після `case 3` **відсутній оператор `break`**, потік виконання "провалюється" у наступний блок (`case 4:`) внаслідок ефекту **fall-through**.
7. Виконується `System.out.println("4")`.
8. На цьому `switch` завершується, загальний вивід: рядки `3` та `4`.

### 15. До якого результату призведе виконання наступного фрагменту коду (true/false)? Перевірте. Поясніть.
```java
double sum = 0;                
// Let's find: 1 + 1/2 + 1/3 + 1/4 + 1/5 + ...
for(int i=1; i<10; i++) {
    sum = sum + 1/i;
}
System.out.println(sum > 1);
```

#### Результат роботи:
```text
false
```

#### Пояснення:
1. У виразі `1/i` константа `1` має тип `int`, а змінна `i` також має тип `int`.
2. За правилами мови Java, операція ділення двох цілих чисел `int / int` є **цілочисельним діленням** (дробова частина відкидається):
   - При `i = 1`: $1 / 1 = 1$. До `sum` додається $1.0$ (значення `sum` стає `1.0`).
   - При `i = 2`: $1 / 2 = 0$ (замість $0.5$).
   - При `i = 3`: $1 / 3 = 0$.
   - Аналогічно для всіх $i \in \{4, 5, 6, 7, 8, 9\}$ результат $1 / i$ дорівнює $0$.
3. У результаті після завершення циклу значення змінної `sum` залишається рівним рівно `1.0`.
4. Умова `sum > 1` (тобто `1.0 > 1.0`) є хибною і дає результат **`false`**.
5. Щоб отримати математично очікувану суму гармонічного ряду, необхідно було використати ділення з плаваючою крапкою: `1.0 / i` або `(double) 1 / i`.
